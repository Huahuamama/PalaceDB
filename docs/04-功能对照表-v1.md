# 功能对照表 v1（原版 CastleDB → C# 重写版）

图例：**✅ 已实现** ／ **◐ 部分实现** ／ **✖ 未实现** ／ **— 按需求删除**

---

## 1. 总体对比

| 维度 | 原版 CastleDB（Haxe + NW.js） | 本版本（C# + WPF + WebView2） |
| --- | --- | --- |
| 运行时 | NW.js（内嵌 Chromium） | .NET 8 + 系统 WebView2 |
| 界面 | Haxe → JS，全量重绘 DOM | HTML5 / ES Modules，虚拟滚动，零构建 |
| 保存模型 | 每次改动立即整库写盘 | **显式保存** + 原子写入 + 脏标记 |
| 撤销 | 全量 JSON 快照（100 步，内存可达 300MB） | **命令模式**（200 步，只存差异） |
| 撤销后光标 | 跳回 (0,0) | **随命令恢复**到操作前位置 |
| 多窗口 | 单进程单窗口 | **单进程多窗口**，独立文档与撤销栈 |
| 同文件并发 | 无保护，后写覆盖 | **第二次打开自动只读**，写方窗口关闭后自动接管 |
| 地图功能 | 有（Layer / TilePos / TileLayer、LZ4 压缩、重映射） | **全部删除**（需求 R1） |
| 图片 | MD5 重命名 + `.img` / `timage` 二进制 | **只存路径字符串**，表格内直接显示缩略图 |
| 元数据 | 混在 `.cdb` 里 | **独立 `X.cdb.meta.json`**，`.cdb` 保持纯净 |

## 7. 类型支持

> 编辑行为：Enum 文本输入按**标签优先**匹配（`1,2,3` 输入 `2` → 标签 `2`）；Flags 先按名字再按掩码；
> Ref 支持在单元格内输入过滤；Color 用调色板并显示色块；List / Properties 展开为二级表格。
>
> Enum / Flags 的取值表**允许某一项没有名字**：`,1,2` 是三项（第一项无标签），`1,,3` 是中间一项无标签。
> 列对话框原样保留空白项，下拉框把这一项显示为灰色的 `(empty)` 并可正常选中；Flags 里的空白项
> 是一个真实的位，`A,,C` 这样的文本会把三项都置上。

> **Id 取值**：`[A-Za-z_][A-Za-z0-9_]*`，或**纯数字**（`0`、`123`、`007`）。指向纯数字 ID 的 Ref 同样接受；
> 复制/插入粘贴遇到重复的数字 ID 时，新 ID 追加数字后缀（`123` → `1232`），保持纯数字形式。
